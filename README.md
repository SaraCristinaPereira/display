# Estudo de Displays no CSS

Projeto desenvolvido para estudar os principais valores da propriedade `display` do CSS e entender seus diferentes casos de uso na construção de páginas web.

## 📚 Sobre o projeto

A propriedade `display` define como um elemento HTML será exibido e como ele irá se comportar em relação aos outros elementos da página.

Neste projeto, são explorados diferentes tipos de `display`, com exemplos práticos em HTML e CSS.

## 🎯 Objetivos

* Entender o funcionamento da propriedade `display`;
* Conhecer os principais valores disponíveis;
* Praticar a diferença entre elementos `block`, `inline` e `inline-block`;
* Estudar o uso de `flex` e `grid`;
* Observar como cada tipo de `display` afeta o layout;
* Aplicar os conceitos em exemplos práticos.

## 🧩 Displays estudados

### `display: block`

O elemento ocupa, por padrão, toda a largura disponível e começa em uma nova linha.

### `display: inline`

O elemento ocupa apenas o espaço necessário para seu conteúdo e permanece na mesma linha de outros elementos.

### `display: inline-block`

Combina características de `inline` e `block`, permitindo que o elemento permaneça na mesma linha enquanto aceita propriedades como `width` e `height`.

### `display: flex`

Utilizado para criar layouts flexíveis, facilitando o alinhamento e a distribuição dos elementos em uma dimensão.

### `display: grid`

Utilizado para criar layouts baseados em linhas e colunas, sendo especialmente útil para estruturas bidimensionais.

### `display: none`

Remove o elemento do fluxo normal da página, fazendo com que ele não seja exibido nem ocupe espaço.
